# DVChat

Закрытый мессенджер для семьи и небольшого круга людей, которым доверяют. Свой сервер, своя
панель администратора, своё приложение. Работает на протоколе Matrix, клиент написан на Flutter:
Android и веб-версия.

Регистрации в приложении нет. Аккаунты выдаёт администратор, вход выполняется по одноразовой
ссылке или QR-коду. Чужие люди и чужие серверы в такой мессенджер не попадают.

DVChat вырос из FluffyChat 2.10.0 (см. NOTICE.md) и от оригинала сегодня сильно отличается:
из него убрано всё лишнее, а сверху построены друзья, истории, восемь игр, ИИ-помощник, обмен
фото с редактором, собственные серверные модули и отдельная панель администратора. Исходный код
открыт по лицензии AGPL-3.0-or-later. Автор: DVB Studio (GitHub: Godween69).

## Из чего состоит проект

В репозитории три части, которые работают вместе.

**Приложение** (каталог lib/). Клиент для Android и веб-версия. Всё интерфейсное, что вы видите
в DVChat, сделано здесь: вкладки, друзья, истории, игры, оформление.

**Серверные модули для Synapse** (каталог server/). Добавляют серверу то, чего нет в обычном
Matrix: вход по одноразовому коду, друзья и заявки, комнаты поддержки, истории, служебные
уведомления, очистку переписки по согласию, запрет самостоятельного создания чатов.

**Панель администратора** (каталог admin/, версия 0.3.3). Локальная веб-панель, которая заменяет
набор отдельных скриптов. Подробности ниже и в admin/README.md.

## Панель администратора

Это главный инструмент владельца сервера. Без неё закрытый мессенджер пришлось бы вести руками.

- **Люди**: создание аккаунта, одноразовая ссылка входа и QR-код, новая ссылка для существующего
  человека, выход на всех устройствах, переименование, удаление с подтверждением.
- **Друзья**: «Подружить людей» (сразу взаимно, с созданием личного чата), «Убрать из друзей».
- **Группы**: администратор создаёт группу, назначает владельца и выходит из неё. Права выдаются
  флажками: приглашать, удалять людей, блокировать, менять название и фото, управлять правами.
- **Комнаты**: список с фильтрами, удаление, очистка переписки. Очистка доходит до телефонов: у
  людей сообщения пропадают и из локальной копии, а не только на сервере.
- **Служебные уведомления**: пуш одному или нескольким людям от имени служебного аккаунта «DVChat».
- **Лиза** (необязательный раздел): состояние ключа, порядок моделей и цены, расход по дням, людям
  и моделям, журнал вопросов, справочник по приложению.
- **Настройка**: проверка связи с сервером и мастер, который сам создаёт файл dvchat.env для сборки.

Безопасность: вход по паролю администратора (хранится только хеш), сессия закрывается через 15
минут простоя, защита от подбора пароля и подделки запросов, строгая политика CSP, журнал
действий без секретов. Панель слушает только локальный адрес.

## Возможности приложения

Своё в DVChat:

- **Вход по приглашению**: ссылка dvchat://login#... или QR-код от администратора.
- **Друзья**: свой ID, добавление по ID или QR-коду, заявки, свои имена для людей (видите только вы).
- **Дни рождения** друзей с напоминаниями.
- **Фото**: сжатие по умолчанию до 1280 пикселей (быстро и экономно), оригинал по выбору;
  редактор с обрезкой, поворотом и рисованием; несколько фото уходят альбомом-коллажем.
- **Список покупок** в чате: общий список, каждый меняет и убирает только свои пункты.
- **Очистка чата по согласию**: в личном чате очистить переписку можно только если согласен
  собеседник.
- **Истории** на сутки, с просмотрами, реакциями и выбором аудитории.
- **Игры**: шахматы, русские шашки, нарды, домино, «Дурак», морской бой, «Четыре в ряд»,
  крестики-нолики. С другом в личном чате или против компьютера без интернета, есть счёт побед.
- **Вкладка «Лиза»**: помощник на основе ИИ (работает при подключённом серверном сервисе).
- **Чат с администратором** и форма обратной связи, **архив чатов**.
- **Оформление**: стеклянные панели и меню, готовые обои, прозрачные шапки.
- **Обновления из собственного канала**, без магазинов приложений.
- Интерфейс только на русском языке.

Основа от FluffyChat: личные и групповые чаты, файлы, голосовые сообщения, сквозное шифрование
и резервная копия ключей.

## Уведомления

Уведомления приходят и при закрытом приложении. Путь такой: Synapse передаёт событие шлюзу
уведомлений Matrix, который работает на вашем сервере, а шлюз отдаёт его в Firebase Cloud Messaging
(это только канал доставки на Android). Адрес шлюза задаётся при сборке (DVCHAT_PUSH_GATEWAY), так
что чужой шлюз не нужен: он стоит у вас. Как его поднять: docs/DEPLOY.md, раздел 6.

## Как устроено

Система состоит из независимых частей:

- **Приложение** (этот репозиторий): Android и веб-версия.
- **Synapse**: сервер Matrix. К нему подключаются модули из каталога server/.
- **Панель администратора** (этот репозиторий, каталог admin/).
- **Шлюз уведомлений** (по желанию): принимает уведомления от Synapse и передаёт их в Firebase.
- **Канал обновлений** (по желанию): любой веб-сервер, отдающий version.json и APK.
- **Сервис «Лиза»** (по желанию, не входит в репозиторий): клиент обращается к нему по адресу
  /lisa/v1/ вашего сервера. Если сервиса нет, вкладка недоступна, остальное работает как обычно.

Приложение привязано к одному серверу, адрес которого задан при сборке (DVCHAT_HOMESERVER в файле
dvchat.env). Это сделано намеренно: оно рассчитано на закрытый круг людей. Скачав исходный код, вы
получаете возможность развернуть собственный мессенджер на своём сервере; к чужим серверам и
чужим сервисам (в том числе к «Лизе») это доступа не даёт.

## Быстрая сборка для проверки

Нужны Flutter версии 3.47.4, Rust (для библиотеки шифрования) и Android SDK.

    git clone https://github.com/Godween69/DVChat.git
    cd DVChat
    flutter pub get
    flutter gen-l10n
    flutter analyze
    cp dvchat.env.example dvchat.env
    flutter run --dart-define-from-file=dvchat.env

В dvchat.env укажите адрес своего сервера Matrix. Подробности: docs/DEPLOY.md.

В репозитории намеренно нет секретов: ключей подписи, google-services.json, адресов серверов
и служебных сервисов (они лежат в вашем dvchat.env).
