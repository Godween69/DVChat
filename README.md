# DVChat

Закрытый семейный мессенджер на протоколе [Matrix](https://matrix.org). Клиент написан на
[Flutter](https://flutter.dev) и работает на Android и в браузере (веб-версия).
Регистрации в приложении нет: аккаунты выдаёт администратор сервера, вход выполняется
по одноразовой ссылке или QR-коду.

DVChat это изменённая версия [FluffyChat](https://github.com/krille-chan/fluffychat) 2.10.0
(см. [NOTICE.md](NOTICE.md)). Исходный код открыт по лицензии AGPL-3.0-or-later.
Автор изменений: DVB Studio.

## Возможности

Из FluffyChat:

- личные и групповые чаты, фото, файлы, голосовые сообщения;
- сквозное шифрование и резервная копия ключей;
- push-уведомления через Firebase, в том числе при закрытом приложении.

Добавлено в DVChat:

- вход по приглашению: ссылка `dvchat://login#...` или QR-код от администратора;
- друзья: свой ID, добавление по ID или QR-коду, заявки;
- чат с администратором и форма обратной связи;
- архив чатов: ушедшие собеседники и скрытые чаты;
- истории (сторис) на сутки, с просмотрами и реакциями;
- игры: шахматы, русские шашки, нарды, домино, «Дурак», морской бой, «Четыре в ряд»,
  крестики-нолики; можно играть с другом в личном чате или против компьютера без интернета,
  есть счёт побед;
- вкладка «Лиза»: помощник на основе ИИ (работает только при подключённом серверном
  сервисе, см. ниже);
- обновления из собственного канала, без магазинов приложений;
- интерфейс только на русском языке.

## Как устроено

Система состоит из нескольких независимых частей. Этот репозиторий содержит клиент
и серверные модули для Synapse.

- **Клиент** (этот репозиторий): приложение для Android и веб-версия.
- **Synapse**: сервер Matrix. К нему подключаются модули из каталога `server/`
  (вход по коду, друзья, комнаты поддержки, истории, запрет самостоятельного создания чатов).
- **Шлюз уведомлений** (по желанию): принимает уведомления от Synapse и передаёт их
  в Firebase. Подойдёт любой шлюз Matrix с поддержкой FCM, например Sygnal.
- **Канал обновлений** (по желанию): любой веб-сервер, отдающий `version.json` и APK.
- **Сервис «Лиза»** (по желанию): не входит в репозиторий. Клиент обращается к нему по
  адресу `/lisa/v1/` вашего сервера. Если сервиса нет, вкладка просто недоступна,
  остальное приложение работает как обычно.

Приложение привязано к одному серверу, адрес которого задан при сборке
(`DVCHAT_HOMESERVER` в файле `dvchat.env`). Это сделано намеренно: оно рассчитано на закрытый круг людей.
Скачав исходный код, вы получаете возможность развернуть **собственный** мессенджер
на своём сервере; к чужим серверам и к чужим сервисам (в том числе к «Лизе») это доступа не даёт.

## Быстрая сборка для проверки

Нужны [Flutter](https://flutter.dev) версии 3.47.4, [Rust](https://www.rust-lang.org/tools/install)
(для библиотеки шифрования) и Android SDK.

    git clone https://github.com/Godween69/DVChat.git
    cd DVChat
    flutter pub get
    flutter gen-l10n
    flutter analyze
    cp dvchat.env.example dvchat.env
    flutter run --dart-define-from-file=dvchat.env

В `dvchat.env` укажите адрес своего сервера Matrix. Подробности: [docs/DEPLOY.md](docs/DEPLOY.md).

В репозитории намеренно нет секретов: ключей подписи, `google-services.json`,
адресов серверов и служебных сервисов (они лежат в вашем `dvchat.env`).
